## Збирання

Потрібні Node.js 22 та mdBook 0.5.4 (та сама версія, що й у GitHub Pages):

```sh
cargo install mdbook --version 0.5.4 --locked
make book
```

## Публікація

GitHub Actions автоматично збирає та публікує сайт на GitHub Pages після push у гілку `main`. Для повторної публікації можна вручну запустити workflow `Publish book` у вкладці Actions репозиторію. У налаштуваннях репозиторію **Settings → Pages → Source** має бути вибрано **GitHub Actions**.

Базовий шлях сайту в `book.toml` — `/eclipsephase-uk/`. Локальний перегляд: `make serve`.

## Оновлення джерела

```sh
node scripts/upstream/check.mjs
```

Перевірка отримує лише метадані GitHub і порівнює вихідні файли для наявних українських сторінок та спільний CSS. Інші мовні видання, згенеровані сайти, виконувані файли та додатки не імпортуються. Виправлену в джерелі назву `05-step-2-career.md` зіставлено з локальною `05-step-2-carrer.md`, щоб зберегти посилання.

GitHub Actions запускає перевірку щопонеділка; її також можна запустити вручну. Код виходу 1 означає, що потрібен перегляд змін, а помилка запиту завершує перевірку з помилкою. Перевірка нічого не змінює в перекладі. Нові розділи, яких ще немає українською, не відстежуються; після їх перекладу додайте відповідні записи до бази.

Для локальної копії джерела без мережевих запитів:

```sh
node scripts/upstream/check.mjs --source /path/to/EclipsePhase2e-ptbr
```

База порівняння — `scripts/upstream/baseline.json`: commit джерела та Git blob SHA кожного відстежуваного файла. Після перегляду й перенесення змін оновіть відповідні SHA та commit у базі. Не змінюйте базу лише для того, щоб перевірка стала успішною.

**База фіксує поточний стан джерела для майбутніх сповіщень, а не завершений перегляд усього перекладу.** Решта історичних змін (зокрема форматування, посилання, архетипи та глосарій) потребує окремої звірки. Українське видання залишається частковим перекладом; його не слід вважати повністю оновленим до v1.4.
